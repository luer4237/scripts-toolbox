# SGuardLimiter

## 功能

调整指定 Windows 进程的 CPU 优先级和处理器亲和性，降低相关进程对系统 CPU 资源的占用。

当前脚本默认处理以下进程：

- `SGuard64`
- `SGuardSvc64`

## 文件

- `SGuardLimiter.ps1`：PowerShell 脚本。

## 平台与依赖

- Windows
- Windows PowerShell 或 PowerShell 7
- 需要管理员权限

## 使用方式

1. 先启动目标游戏，使相关进程加载完成。
2. 以管理员权限运行 `SGuardLimiter.ps1`。
3. 脚本会查找目标进程，并尝试将其优先级设置为 `Idle`，同时限制其处理器亲和性。

每次重新启动目标游戏后，可能需要重新运行脚本。

## 注意事项

- 脚本只处理运行中的目标进程，未运行的进程会被跳过。
- 修改进程调度策略可能影响程序行为，请根据实际情况使用。
- 脚本涉及进程权限和系统调度设置，运行前请确认脚本来源可信。
